This page reads its data from ingredients.json sitting next to it, and some browsers block that load when the page is opened straight from disk. Serve it from the site (for example GitHub Pages) and it will load. The data file itself is unchanged.

Item lines link to Walmart search for that item, so you can check the current listing. Prices shown are what was actually paid on Oct 24, 2026, not current Walmart prices.

To update for the next event, edit ingredients.json only: change a quantity or price, add or remove an item, or set its category to event, personal, or home. Every total on this page recomputes itself.
